## 4. Архитектурные решения

- `PlaybackArbiter` — единственное место, где решается, кто звучит. `PlaybackEngine` и YouTube не знают друг о друге. Внешний плеер реализует `ExternalPlayer` (play, pause, active, overlay) — это готово для E3 (SoundCloud widget) без изменений арбитра.
- Медиапанель Windows показывает плеер, запущенный последним. Windows превращает клавишу Play/Pause в Play или Pause по состоянию панели; это доказано в E2.0, R3.
- Поиск YouTube — отдельный клиент и отдельная секция, не `MusicSource`. YouTube не даёт поток для `PlaybackEngine`, а его результаты нельзя смешивать с другими каталогами (Developer Policies III.C.5, III.F.2).
- Ключ хранится как client id Jamendo: только в локальной базе. Проверка ключа стоит 1 единицу квоты.
- Требования YouTube API (проверены 2026-10-26, Developer Policies / RMF от 2026-10-15):
  - квота по умолчанию — 10 000 единиц в сутки, поиск стоит 100, `videos.list` — 1;
  - данные API хранятся не дольше необходимого (III.E.4) — у NEXA только память сеанса;
  - Made for Kids — нет отслеживания;
  - обновления клиента (III.B.1) — плеер загружается с YouTube при каждом открытии.

## 7. Ошибки, ограничения, технический долг

- Видео запускается со звуком кнопкой NEXA вне веб-страницы, поэтому WebView2 может заблокировать автозапуск. Тогда показывается «Press play in the YouTube player»; одно нажатие play в плеере YouTube.
- Поиск только с собственным ключом владельца; ~99 поисков в сутки по стандартной квоте Google.
- Ключ в настольном приложении нельзя защитить абсолютно: он хранится в локальной базе NEXA. Рекомендация — ограничить его YouTube Data API v3.
- YouTube и Google видят просмотры, IP и свои cookies во встроенном WebView2. Это сказано на экране согласия; очистка — удаление папки `webview2` в данных NEXA (`docs/E2_YOUTUBE.md`).
- Нет очереди и плейлистов YouTube, YouTube не в Wave / DNA / истории — так задумано (CR-001).
- Нужен WebView2 Runtime (есть в Windows 11). Компьютер без него не проверялся; путь «недоступно» покрыт unit-тестом.
- Версия приложения осталась 1.0.0+8: номер версии для E2 не менялся, его решает владелец при выпуске.
