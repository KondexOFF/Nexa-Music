# NEXA Music — Development Reports

Claude writes a factual report **after each explicitly approved phase**, then stops.

- `PHASE_00_REPORT.md` — Phase 0 proof-of-environment and audio experiment.
- `PHASE_01_REPORT.md` … `PHASE_07_REPORT.md` — only after corresponding work.
- `FINAL_DEVELOPMENT_REPORT.md` — only after approved Phase 7.

**Template:** the 11-section report in `../NEXA_Music_Master_Plan_Claude.md` (Section 7). Required: planned vs actual, files, decisions, exact commands/output codes, three manual scenarios, bugs, approved CR identifiers (or NONE), screenshot paths, explicit not-done scope, request for owner acceptance.

Use **NOT RUN** for unexecuted checks. No fabricated screenshots, fake PASS, token values, secrets, listening history, absolute personal file paths, copyrighted audio or raw private logs. Sanitized textual test evidence may be tracked. Owner decides whether a report can be pushed.
