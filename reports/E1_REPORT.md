## 4. Архитектурные решения

- Подбор для Wave — новый метод того же интерфейса `MusicSource` (ARCHITECTURE.md: источник объявляет свои возможности).
- Онлайн и локальные треки ранжируются одним `WaveRanker`, затем смешиваются по Discovery — объяснимо и проверяемо.
- Онлайн-пул живёт только в памяти контроллера (условия Jamendo о кэше, Audius «active streaming use only»).
- Переключатель выключен по умолчанию, потому что включение отправляет данные вкуса во внешние службы (Master Plan, раздел 5.7). Решение D-021.

## 7. Ошибки, ограничения, технический долг

- Wave по-прежнему требует хотя бы один трек в библиотеке (онлайн-только Wave не делался).
- Jamendo работает только с client id владельца; Audius сейчас работает без ключа, но может потребовать его в будущем (тогда — заметка, Wave продолжает библиотекой).
- Сопоставление жанров: Audius — только официальный список и несколько синонимов; Jamendo — нормализация названия в тег. Нестандартные жанры каталогам не отправляются / могут не совпасть.
- Онлайн-треки не лайкаются, не попадают в плейлисты и историю; «Not for me» действует до закрытия NEXA (сохранение потребовало бы хранить данные каталогов — не делалось по условиям).
- Обнаружение «мёртвого» потока опирается на сообщение об ошибке libmpv; проверено для HTTP 404 и недоступного адреса.
- Группы playback / mix AutoTest на сборке E1 не повторялись (длинные тестовые тоны; E1 меняет плеер только в обработке ошибки потока, покрыто unit- и Windows-тестами). Можно запустить по запросу.
- Версия на ветке осталась 1.0.0+8; новая версия — по решению владельца.
