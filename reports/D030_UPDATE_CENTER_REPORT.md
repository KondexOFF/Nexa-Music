## 1. Что сделано

- **Проверка обновлений**:
  - автоматически при запуске, не чаще раза в сутки, отключается в Settings → About;
  - вручную — «Check for updates» в Settings → About;
  - черновики и пре-релизы GitHub не предлагаются.
- **Уведомление** с четырьмя действиями: «Update now», «What's new», «Later», «Skip this version». Без нажатия ничего не скачивается.
- **Источник релизов**:
  - публичный GitHub API без авторизации;
  - для приватного репозитория — авторизованный GitHub CLI владельца (`gh`). NEXA не видит, не хранит и не пишет токен: `gh` хранит его в Windows Credential Manager и отправляет только на github.com.
- **Целостность загрузки**:
  - обязателен SHA-256 из данных GitHub о файле релиза (`digest`);
  - он должен совпасть с `SHA256SUMS.txt` релиза;
  - нет контрольной суммы — установки нет.
- **Проверка архива до распаковки**: абсолютные пути, `..`, `\`, `:`, точки и пробелы в конце имён, имена устройств, ссылки и reparse points, дубли без учёта регистра, файл одновременно папкой, шифрование, CRC-32 каждого файла.
- **Распаковка** во временную папку вне папки программы, затем сверка каждого файла со списком пакета.
- **Отдельный установщик Windows** (`assets/updater/nexa_updater.ps1`):
  - ждёт закрытия NEXA и сохраняет текущую версию;
  - меняет папки местами, а если переименование невозможно — копирует на место;
  - запускает новую версию и ждёт её подтверждения;
  - если подтверждения нет, возвращает прежнюю версию и запускает её.
- **Откат** в Settings → About. Если база уже обновлена новой версией:
  - NEXA сначала объясняет это и спрашивает;
  - возвращает копию базы, сделанную до миграции;
  - текущую базу сохраняет защищённой копией, которая автоматически не удаляется.
- **Новая база в старой версии**: 1.1.1 никогда не открывает базу более новой версии и предлагает вернуть совместимую копию; текущий файл при этом сохраняется.

## 4. Что не проверено на Windows и почему

- **«Install when I close NEXA»** проверено unit-тестом контроллера. В Windows-цепочке установка запускалась через «Restart and install» — тот же установщик и тот же план.
- **Нехватка места на диске** проверена unit-тестом. Заполнять диск ПК владельца ради проверки нельзя.
- **Приватный репозиторий без `gh`, без входа и без доступа** — unit-тесты сообщений `gh`. Репозиторий сейчас публичный (решение владельца), поэтому `gh` проверен на настоящем аккаунте, но отказ в доступе не воспроизводится.
- **Реальное обновление с GitHub на следующую версию** будет возможно, только когда выйдет 1.2.0. Механизм проверен на тех же запросах GitHub API через локальную замену; настоящий GitHub проверен для списка релизов и загрузки v1.1.0.
