# NEXA Music 1.1.0 — Windows x64

Личный музыкальный плеер для Windows 10 / 11 x64. Portable-сборка: папку `NEXA_Music_1.1.0_Windows_x64` можно положить в любое место и запустить `nexa_music.exe`. Установка не нужна, среда выполнения Visual C++ лежит в папке.

## Новое в 1.1.0

- **YouTube** — официальный плеер YouTube внутри NEXA (видимый, с рекламой и правилами YouTube):
  - вставленная ссылка работает без ключа, поиск — с вашим ключом YouTube Data API;
  - плеер на странице, компактный в углу, во весь экран и в мини-окне поверх других программ; видео не перезагружается при переходах.
- **SoundCloud** — официальный виджет SoundCloud. Работают ссылки на треки, плейлисты (sets) и профили, в том числе короткие ссылки. Поиска внутри NEXA нет (см. ограничения), есть переход на поиск soundcloud.com.
- **Одна очередь для всех источников** — библиотека, Audius, Jamendo, YouTube и SoundCloud подряд. Если Windows не дала запустить видео само, появляется «Continue». Очередь восстанавливается после перезапуска.
- **Избранное, плейлисты и закладки** — для всех источников. Записи, которые сейчас недоступны, показываются серыми и пропускаются.
- **История** — Recently Played и Continue Listening. Пишется только с вашего согласия. История YouTube — отдельный переключатель, только с ключом; видео «для детей» не записываются.
- **NEXA Wave по каталогам:**
  - онлайн-подборки Audius и Jamendo (по желанию);
  - доля Library / Online;
  - правый край ползунка «Online only» — только новые онлайн-рекомендации.
- **Smart Mix** измеряет файлы библиотеки в фоне и запоминает результат:
  - тихий хвост песни пропускается;
  - переход начинается там, где затухло аутро;
  - следующая песня начинается со звука.
  Онлайн-песни получают обычный crossfade.
- **Crossfade** работает и для потоков Audius / Jamendo.
- **Блокировка рекламы в веб-плеерах** (по желанию, выключена по умолчанию; Settings → Privacy). Используется локальный uBlock Origin Lite: его .zip скачивается с официальной страницы, NEXA сама его распаковывает. Выключить или удалить полностью можно в один клик. Нарушает правила YouTube API, блокировка не гарантируется.
- **Удобство:**
  - размер и положение окна запоминаются;
  - назад / вперёд — Alt + ← / → и боковые кнопки мыши;
  - в Settings видно текущее устройство вывода;
  - сохранённое устройство применяется при запуске.
- **Резервные копии** базы: перед каждой миграцией, вручную и восстановление.

## Данные

Библиотека, плейлисты, настройки и история хранятся в `%APPDATA%\com.kondexoff\nexa_music`, а не в папке программы. При первом запуске 1.1.0 база обновляется (схема 3 → 4). Перед этим автоматически делается её копия в папке `backups`. Версию 1.0.0 можно оставить рядом.

## Известные ограничения

- YouTube: без своего ключа Data API нет поиска и истории. Crossfade, фоновое воспроизведение и скачивание невозможны — так требуют условия YouTube.
- SoundCloud:
  - поиска внутри NEXA нет: ключи API выдаются только с платной Artist Pro, а условия API противоречат общей очереди и кэшу;
  - звук только в виджете, поэтому нет crossfade и нет SoundCloud в Wave.
- Smart Mix анализирует только файлы библиотеки. Громкость между песнями не выравнивается, темп и тональность не учитываются.
- Блокировка рекламы:
  - не входит в NEXA, обновления — вручную;
  - если плеер уже открывался с выключенной блокировкой, после её включения нужен перезапуск NEXA (кнопка в Settings).
- Теги WAV в кодировке Windows-1251 читаются неверно; номера треков в WAV не читаются.
- Для Jamendo нужен свой client id.
- `nexa_music.exe` не подписан: при первом запуске Windows SmartScreen может предупредить («Подробнее» → «Выполнить в любом случае»).

Проверка: `reports/RELEASE_1.1.0_READINESS.md` в репозитории.
