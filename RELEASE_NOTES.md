# NEXA Music 1.0.0 — Windows x64

Личный музыкальный плеер для Windows 10 / 11 x64. Portable-сборка: папку `NEXA_Music_1.0.0_Windows_x64` можно положить в любое место и запустить `nexa_music.exe`. Установка не нужна, среда выполнения Visual C++ лежит в папке.

## Что умеет

- **Своя библиотека:** MP3, FLAC и WAV из ваших папок (файлы не копируются, не перемещаются и не изменяются), теги и обложки, поиск (в том числе по-русски), избранное, плейлисты, повторное сканирование. Работает без интернета.
- **Воспроизведение:** очередь, Shuffle и Repeat, громкость и Mute, выбор устройства вывода, медиаклавиши и медиапанель Windows, горячие клавиши (Space, Ctrl + стрелки, Ctrl + M).
- **NEXA Mix Engine:** Gapless (переходы без пауз), Crossfade 0–12 с, Smart Mix; треки одного альбома играют без наложения.
- **NEXA DNA и NEXA Wave:** вкус задаётся явно, лайки и дизлайки, история хранится только локально и только с вашего согласия, есть Private session; бесконечная волна из своей библиотеки с объяснением «почему этот трек».
- **Discover:** поиск и прослушивание Audius и Jamendo через официальные API (только потоковое воспроизведение; источник и лицензия указаны). Для Jamendo нужен свой client id (Settings → Online catalogs).

## Исправлено в финальной проверке

- Режим Gapless: каждая третья песня подряд пропускалась, треки обрезались, между ними была тишина 50–80 мс (TD-20).
- Последняя песня очереди обрезалась примерно на 0,3 с (TD-22).
- FLAC-файлы с ID3-тегом в начале читались без названия и с неверной длительностью (TD-19).
- Кириллица в тегах WAV (UTF-8) отображалась неверно (TD-04).

## Известные ограничения

- Теги WAV в кодировке Windows-1251 читаются неверно; номера треков в WAV не читаются.
- Smart Mix v1 учитывает длину треков и порядок альбома, но не анализирует тишину и уровень.
- Песни из Audius и Jamendo нельзя лайкать, добавлять в плейлисты и в историю; они не микшируются.
- `nexa_music.exe` не подписан: при первом запуске Windows SmartScreen может предупредить («Подробнее» → «Выполнить в любом случае»).

## Данные

Библиотека, плейлисты, настройки и история хранятся в `%APPDATA%\com.kondexoff\nexa_music`, а не в папке программы. Новую версию можно положить рядом со старой или вместо неё: данные сохраняются.

Проверка: автоматический финальный тест NEXA AutoTest и ручная приёмка владельцем (30 из 30 сценариев), см. `reports/RELEASE_1.0.0_READINESS.md` в репозитории.
